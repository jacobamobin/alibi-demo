# Alibi generated assets

Generated with the built-in ImageGen tool on November 1, 2026. These are fictional people, not contact imports or likenesses of real people.

The following records the generation briefs. It is a concise archive of the requested content and constraints, not a verbatim API transcript.

## Desktop concept

Design a polished FaceTime-style Alibi application at approximately 1440 × 1000. Use three equal desktop columns. Left: Alibi identity, People cards for Owen Brooks, Maya Chen, and Leo with George, Sarah, and Liam voices; New person; a shared board-game-night scene editor. Center: a dark framed phone call with three static fictional portrait tiles, two above and one spanning below; “Preview · audio off”, a timer, and glass microphone, speaker, add-person, more, and red hang-up controls. Right: shared context, empty live transcript, local session joins, and Settings. Near-black Apple-style interface with restrained gray borders and green accents. No fabricated dialogue, dashboards, metrics, or marketing content.

Output: `alibi-desktop-concept.png`. The implementation omits the concept's fake OS status bar so the real phone owns its browser/system chrome.

## Production portrait atlas

Create three original photorealistic adult fictional friends in equal-width vertical portraits, side by side in a single image, without text or UI. Left: Owen, friendly bearded dark-haired man in a white T-shirt. Middle: Maya, friendly dark-haired woman in a forest-green shirt. Right: Leo, friendly man with curly light-brown hair in a navy shirt. Casual warm apartment interiors, natural webcam-like framing, softly lit faces, consistent realism and image quality. All characters invented, no reference to a real person's likeness.

Output: `web/public/portraits/cast.png`. An SVG viewport displays one third of the atlas for each person. New fictional contacts use monograms.

## WhatsApp-style redesign and additional contacts

Built-in ImageGen was used for a three-column WhatsApp-style group voice-call design reference (`alibi-whatsapp-concept.png`), a home-screen microphone design reference (`alibi-whatsapp-home-concept.png`), and seven additional original fictional adult portraits in a 4×2 atlas with one blank cell (`web/public/portraits/extended.png`).

Design briefs: preserve desktop equal thirds and phone full-screen calling; use WhatsApp dark blue-black #0b141a, surfaces #111b21/#1f2c34, green #25d366, circular profile photos, round controls and red hang-up. Keep Alibi branding and fictional-call labels, with no false encryption claims. The home screen has Set the scene, a microphone/Listening control, Demo mute, captured context, a scrollable People list, New call, and Silent preview. Later user steering explicitly removed a forced pre-call wizard: listening starts on home and New call inherits its context.

Portrait brief: exactly seven original fictional adults, evenly framed for circular cropping, no text/borders/gutters. Top row Noah (cropped dark hair/beard/rust tee), Zara (dark curls/teal), Finn (sandy hair/freckles/cream overshirt), Alex (short textured hair/glasses/gray). Bottom row Amelia (auburn hair/beige knit), Jules (black bob/navy), Eli (wavy dark hair/olive), and a blank charcoal cell. Natural soft lighting, casual backgrounds, consistent photorealism; no real likenesses.
